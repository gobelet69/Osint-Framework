# Gobelet's OSINT Framework

A curated, up-to-date collection of tools and resources for Open Source Intelligence (OSINT), organized for practical investigations.

---

## Categories

### 1. Username & Identity Search
- [NexFil **(NEW)**](https://github.com/thewhiteh4t/nexfil) - Fast username discovery across social platforms.
- [What's My Name](https://whatsmyname.app/) - Platform-aware username enumeration with high OSINT community trust.
- [Sherlock](https://github.com/sherlock-project/sherlock) - CLI username hunting across hundreds of services.
- [Maigret **(NEW)**](https://github.com/soxoj/maigret) - Advanced username OSINT with customizable checks and reporting.
- [IntelTechniques Username Search](https://inteltechniques.com/tools/Username.html) - Fast browser-based username pivoting.

### 2. Domain, Infrastructure & Web Recon
- [FOFA **(NEW)**](https://en.fofa.info/) - Cyber asset search engine for exposed systems and services.
- [Web Check](https://web-check.xyz/) - All-in-one technical website profiling.
- [urlscan.io **(NEW)**](https://urlscan.io/) - Web page scanning and internet exposure context.
- [SecurityTrails **(NEW)**](https://securitytrails.com/) - DNS, WHOIS, and historical internet asset intelligence.
- [Shodan **(NEW)**](https://www.shodan.io/) - Search engine for internet-exposed devices and services.
- [Censys **(NEW)**](https://search.censys.io/) - Internet-wide host and certificate intelligence.
- [Netlas **(NEW)**](https://netlas.io/) - Asset, certificate, and web exposure discovery.

### 3. Image Search (Reverse & Face)
- [TinEye](https://tineye.com/) - Reverse image search for source discovery and reuse tracking.
- [Google Images](https://images.google.com/) - Broad reverse image search coverage.
- [Yandex Images](https://yandex.com/images/) - Strong visual matching for objects and locations.
- [Bing Visual Search **(NEW)**](https://www.bing.com/visualsearch) - Additional reverse image index for cross-validation.
- [PimEyes](https://pimeyes.com/) - Face similarity search (use with legal and ethical constraints).

### 4. Image, Media & Metadata Analysis
- [FFmpeg **(NEW)**](https://ffmpeg.org/) - Extract, inspect, and transform media streams for analysis.
- [ExifTool](https://exiftool.org/) - Metadata extraction and normalization across media formats.
- [Forensically](https://29a.ch/photo-forensics/) - Browser-based image forensic analysis suite.
- [Photopea](https://www.photopea.com/) - Quick layered inspection and enhancement workflow.
- [hexed.it](https://hexed.it/) - Browser hex editor for binary/media header inspection.
- [InVID & WeVerify **(NEW)**](https://www.invid-project.eu/tools-and-services/invid-verification-plugin/) - Video keyframe extraction and verification support.

### 5. Geospatial & Location Intelligence (GEOINT)
- [Google Maps](https://www.google.com/maps) - Basemap, POI, and route context.
- [Google Earth](https://earth.google.com/) - 3D terrain and historical imagery workflows.
- [OpenStreetMap](https://www.openstreetmap.org/) - Community geospatial data baseline.
- [Overpass Turbo](https://overpass-turbo.eu/) - Query and extract OSM features for evidence mapping.
- [Mapillary **(NEW)**](https://www.mapillary.com/) - Street-level imagery for location corroboration.
- [Sentinel Hub EO Browser **(NEW)**](https://apps.sentinel-hub.com/eo-browser/) - Satellite imagery access for temporal checks.

### 6. Search Tradecraft & Archiving
- [Google Hacking Database (GHDB)](https://www.exploit-db.com/google-hacking-database) - Curated operator queries.
- [Wayback Machine](https://web.archive.org/) - Historical web snapshots and change tracking.
- [Google Advanced Search](https://www.google.com/advanced_search) - Precision search controls.
- [IntelTechniques Search Tools](https://inteltechniques.com/tools/) - Practitioner-focused search pivots.
- [Wikimedia XTools](https://xtools.wmcloud.org/) - Historical edit and account analysis for Wikimedia.

### 7. Social Media & Content Discovery
- [CrowdTangle (Meta) **(NEW)**](https://www.crowdtangle.com/) - Historical and trend discovery for public Facebook/Instagram content.
- [X Advanced Search](https://x.com/search-advanced) - Native advanced query interface for X.
- [Social Searcher **(NEW)**](https://www.social-searcher.com/) - Multi-platform social post discovery.
- [Nitter instances (where available)](https://github.com/zedeus/nitter/wiki/Instances) - Alternative public X viewing for research continuity.
- [Meltwater Explore](https://www.meltwater.com/en/products/explore) - Enterprise-scale social listening and monitoring.

### 8. Email, Person & Organization Enrichment
- [DeHashed **(NEW)**](https://www.dehashed.com/) - Breach intelligence search for account attribution and exposure checks.
- [Hunter](https://hunter.io/) - Domain-based email discovery and verification.
- [Epieos](https://epieos.com/) - Email/identifier-to-account pivoting.
- [theHarvester **(NEW)**](https://github.com/laramies/theHarvester) - Email, subdomain, and OSINT source aggregation.
- [Maltego](https://www.maltego.com/) - Graph link analysis and investigative pivoting.
- [SpiderFoot **(NEW)**](https://github.com/smicallef/spiderfoot) - Automated reconnaissance and enrichment.
- [Have I Been Pwned **(NEW)**](https://haveibeenpwned.com/) - Breach exposure checks for accounts and domains.

### 9. Crypto, Encoding & Data Transformation
- [CyberChef](https://gchq.github.io/CyberChef/) - Analyst workbench for decoding, parsing, and transforms.
- [Cryptii](https://cryptii.com/) - Interactive encode/decode and data conversion workflows.
- [OpenSSL](https://www.openssl.org/) - Command-line cryptographic toolkit.
- [dCode](https://www.dcode.fr/en) - Broad cipher/encoding analysis and helpers.

### 10. File Analysis & Reverse Engineering
- [Binwalk](https://github.com/ReFirmLabs/binwalk) - Firmware and binary extraction/analysis.
- [Ghidra](https://ghidra-sre.org/) - Open-source reverse engineering suite.
- [IDA Free](https://hex-rays.com/ida-free/) - Interactive disassembly for static analysis.
- [Dogbolt](https://dogbolt.org/) - Multi-decompiler comparison for binaries.
- [Cutter **(NEW)**](https://cutter.re/) - User-friendly reverse engineering frontend.

### 11. Investigation Platforms & Frameworks
- [Bellingcat Online Investigation Toolkit](https://bellingcat.gitbook.io/toolkit) - Community-standard investigative tool index.
- [OSINT Framework](https://osintframework.com/) - Broad category-based OSINT navigation map.
- [Trace Labs OSINT VM **(NEW)**](https://www.tracelabs.org/initiatives/osint-vm) - Prebuilt OSINT analyst environment.
